# Rosa Merger

Loja virtual de bolsas artesanais, desenvolvida com Next.js e TypeScript.

O projeto tem como objetivo apresentar e comercializar bolsas feitas artesanalmente, oferecendo duas modalidades:

- **Pronta entrega:** compra diretamente pela plataforma.
- **Sob encomenda:** solicitação personalizada por meio de contato via WhatsApp.

## Tecnologias

- Next.js
- TypeScript
- PostgreSQL
- Supabase
- Drizzle ORM
- Vercel
